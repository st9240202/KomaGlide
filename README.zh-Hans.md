# KomaGlide

[繁體中文](README.md) · [日本語](README.ja.md) · [English](README.en.md) · **简体中文**

在漫画原网站连续阅读，并自动将已加载的正文图片保存到该网站的 IndexedDB。iPhone 上的 Gear 和桌面端的 Tampermonkey 使用同一份 [KomaGlide 用户脚本][install]。阅读器、书库界面和网站识别功能都包含在脚本中。

## 安装与自动更新

1. 在 iPhone 上用 Gear 打开[安装链接][install]，按提示安装并启用脚本。也可以将文件保存到「文件」App，再从 Gear 的用户脚本管理界面导入。桌面用户请在已启用 Tampermonkey 的浏览器中打开同一链接。
2. 打开支持的漫画章节，例如 [xkcd 第 1 话](https://xkcd.com/1/)。原网站加载图片后，KomaGlide 会显示已保存的页数。首次阅读新页面时需要连接漫画网站，之后阅读器会优先读取已保存的图片。

从 0.7.10 起，脚本管理器可根据更新设置从 GitHub 检查并下载新版。如果之前是从本地文件导入或手动粘贴旧版代码，请先用[安装链接][install]更新一次。

[install]: https://raw.githubusercontent.com/st9240202/KomaGlide/main/dist/komaglide.user.js

## 打开书库

在普通网页中打开 Gear 或 Tampermonkey 的脚本菜单，选择「打开 KomaGlide 书库」。书库会在新的前台标签页打开。在保存过漫画的网站上，会打开该站书库。从其他网站打开时，会前往最近记录的漫画站。如果还没保存过漫画，会显示当前网站的空书库。漫画页面右下角的「书库」按钮会显示保存进度，点击即可打开本站书库。阅读和保存图片都在原标签页完成。

书库按网站来源分别存储。每站默认上限为 1 GiB，容量设置、整话清理以及作品和单话收藏按站管理。清除该站的网站数据会同时清除已保存的图片。旧版集中书库里的图片仍归属于旧书库网址。当前版本会在你阅读原网站时建立该站的缓存。

书库界面直接从脚本加载。重启 Gear 或 Chrome 后，浏览器仍需要打开该站的网页才能运行脚本。飞行模式下，首次打开时可能无法通过书签进入书库。书库打开后，可以直接从本地读取已保存的页面。

## 切换界面语言

默认语言为繁体中文。打开 KomaGlide 书库，在上方的「语言」中选择繁體中文、日本語、English 或简体中文。设置会应用到书库、阅读器和脚本菜单，同一脚本管理器内的各漫画站共用该设置。已打开的漫画标签页刷新后会应用新语言。作品与章节名称沿用原网站的内容。

## 阅读操作

在漫画标签页中点击「纵向阅读器」，即可使用纵向滚动、单页和双页模式。在同一页停留约 1 秒后，阅读器默认会逐页预载整话，从当前页向后加载，再补齐前面缺少的页面。也可以在「阅读设置」的「缓冲模式」中选择「只预载后面 3 页」。阅读器会记住你的选择，两种模式都优先读取书库中已有的图片。左侧设置可切换外观、翻页方向和点击翻页。右侧导航可翻页、用缩略图选页或前往相邻章节。读到章节末尾可继续下一话，阅读器会记住「自动接下一话」的设置。

漫画柜支持原网站的选页功能和连续滚动。原网站的选页器停在第 1 页时，向下滚动加载的正文图片也会按图片下方的页码保存。

内置网站识别支持 xkcd、Pepper&Carrot、8comic 的指定阅读页面、看漫画繁体版（漫画柜）的桌面阅读页面，以及 nhentai.net 的图库与单页阅读页面。部分网站的手机版使用不同的网址或页面结构，能否识别取决于具体页面。每张缓存图片的上限为 32 MiB。

## 构建

运行 `node scripts/build.mjs` 生成 `dist/komaglide.user.js`，可通过第一个参数指定输出目录。安装后即可在设备上直接阅读、保存图片和打开书库。

发布新版时，先提高 `src/userscript.meta` 的 `@version`，重新构建，再将源代码和安装文件一起推送到 `main`。脚本管理器会在下次检查更新时发现新版本。

## 添加网站支持

在 `src/sites/` 中添加一个 JavaScript 文件，使用 `siteAdapters.push(function (root, address) { … })` 注册适配器。可以参考 [Pepper&Carrot 适配器](src/sites/pepper-carrot.js)。构建时按文件名顺序纳入各适配器，最后才使用[通用识别](src/sites/generic.js)。

- `root` 是当前网页或尚未插入页面的下一页内容，`address` 是该页网址。从传入的 `root` 读取内容，便于两种阅读方式共用适配器。
- 网页不匹配时返回 `null`。匹配成功时提供稳定的 `chapterId`、`chapterTitle`、`chapterUrl`、`workId`、`workTitle` 和 `entries`。每个条目包含正文图片元素 `img` 和从 1 开始的页码 `index`。如果无法确认作品，将作品字段留空。
- 可以提供已知总页数 `total` 和打开阅读器时的起始页码 `startIndex`。`nextPage` 指向本话下一页，`nextChapter` 指向下一话。省略时采用通用链接识别，指定为 `null` 时在此结束。仅在同源页面间继续加载。
- 原网站随滚动加载图片时，可以提供 `revealPage(index)`，将原网站上对应页面滚动到视口内，并返回是否找到该页。弹出式阅读器会先查书库，仅在该页缺失且原网站尚未提供图片网址时调用该函数。
- 原网站一次显示一张图时，可以提供异步的 `resolvePage(index, signal)`。阅读器会先查书库，缺页时才操作原网站的选页器。等到页码与已加载的图片一致后，返回该页的条目。参见[漫画柜适配器](src/sites/manhuagui.js)。
- 能独立加载各页的适配器可以设置 `parallelPages: true`，并用 `defaultParallelPreload` 指定默认并行数（1–6，省略时为 3）。用户可在阅读设置中覆盖当前网站的并行数，也可选择「使用网站默认值」恢复。
- 重新构建并安装输出的脚本。请在直接打开章节、在原标签页连续阅读、使用弹出式阅读器和从菜单打开书库这四种场景中验证页序与网络请求。

## 测试

[独立脚本测试](tests/standalone.cjs)使用模拟漫画页面，验证移动端尺寸下的自动保存、关闭标签页后读取同一图片，以及从其他网站的脚本菜单打开书库。运行 `TEST_BROWSER=webkit node tests/standalone.cjs` 即可执行 WebKit 版本。

[桌面集成测试](tests/browser-smoke.cjs)使用 Chromium 和官方 Tampermonkey。另有 [8comic](tests/8comic.cjs)、[漫画柜](tests/manhuagui.cjs)及[单站容量上限](tests/library-capacity.cjs)的测试。浏览器测试需要 Playwright Core 和相应的浏览器。
