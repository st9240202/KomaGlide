# KomaGlide

[繁體中文](README.md) · **日本語** · [English](README.en.md) · [简体中文](README.zh-Hans.md)

漫画を配信元のサイトで続けて読みながら、読み込んだ本編画像をそのサイトの IndexedDB に自動保存します。iPhone の Gear とデスクトップの Tampermonkey で同じ [KomaGlide ユーザースクリプト][install]を使えます。リーダー、本棚、サイトの判定機能はすべてこのスクリプトに含まれています。

## インストールと自動更新

1. iPhone では Gear で[インストールリンク][install]を開き、案内に従ってスクリプトをインストールして有効にします。ファイルを「ファイル」アプリに保存し、Gear のスクリプト管理画面からインポートすることもできます。デスクトップでは Tampermonkey を有効にしたブラウザーで同じリンクを開きます。
2. [xkcd の第1話](https://xkcd.com/1/)など、対応する漫画のページを開きます。配信元サイトが画像を読み込むと、保存済みのページ数が表示されます。初めて読むページには配信元サイトへの接続が必要です。次回からは、保存済みの画像があれば優先して読み込みます。

0.7.10 以降は、スクリプト管理ツールの更新設定に従って GitHub で新しいバージョンを確認し、ダウンロードできます。以前にローカルファイルからインポートしたり、コードを貼り付けて導入したりした場合は、[インストールリンク][install]から一度更新してください。

[install]: https://raw.githubusercontent.com/st9240202/KomaGlide/main/dist/komaglide.user.js

## 本棚を開く

通常のウェブページで Gear または Tampermonkey のスクリプトメニューを開き、**KomaGlide の本棚を開く**を選びます。本棚は新しいタブで前面に開きます。漫画を保存したことのあるサイトでは、そのサイトの本棚が開きます。別のサイトから開くと、最後に記録した漫画サイトの本棚に移動します。まだ漫画を保存していない場合は、現在のサイトの空の本棚が表示されます。漫画ページの右下にある **本棚** ボタンには保存状況が表示され、押すとそのサイトの本棚が開きます。閲覧と画像の保存は元のタブで行われます。

本棚はサイトのオリジンごとに分かれ、既定の容量上限は各 1 GiB です。容量設定、話単位でのキャッシュ削除、作品や話のお気に入りはサイトごとに管理されます。サイトデータを消去すると、保存済みの画像も削除されます。旧バージョンの共通本棚に保存した画像は、その本棚の URL に紐付いています。現行バージョンでは、配信元サイトで閲覧したときにサイトごとのキャッシュを作成します。

本棚の画面はスクリプトから直接読み込まれます。Gear や Chrome を再起動した後は、ブラウザーで対象サイトのページを開くとスクリプトが実行されます。機内モードでは、ブックマークから本棚を開けないことがあります。本棚が開いていれば、保存済みの画像を端末内から直接読み込めます。

## 表示言語を変更する

既定の言語は繁体字中国語です。KomaGlide の本棚を開き、上部の **言語** から繁體中文、日本語、English、简体中文を選べます。設定は本棚、リーダー、スクリプトメニューに反映され、同じスクリプト管理ツール内の漫画サイトで共通です。すでに開いている漫画のタブには、再読み込みすると反映されます。作品名と話のタイトルは配信元サイトの表記を使います。

## リーダーの操作

漫画ページで **縦読みリーダー** を選ぶと、縦スクロール、単ページ、見開きで閲覧できます。既定では同じページに約1秒とどまると、現在のページから順に話の最後まで先読みし、その後で手前の未取得ページを補完します。**閲覧設定** → **先読みモード** では **次の3ページだけ先読み** も選べます。選択は保存され、どちらのモードでも本棚の画像が優先されます。左側の設定では外観、ページをめくる方向、タップ操作を切り替えられます。右側のメニューではページをめくる、サムネイルから選ぶ、前後の話に移動するといった操作ができます。話の終わりから次の話に進めます。**自動で次の話へ** の設定も保存されます。

漫画櫃のデスクトップ版では、配信元サイトのページ選択と連続スクロールに対応しています。ページ選択が1ページ目のときは、下にスクロールして読み込んだ画像も、画像の下に表示されたページ番号で保存します。モバイル版では一覧から話を開き、「先読み開始」で全ページを保存したり、「縦読みリーダー」で閲覧したりできます。

内蔵のサイト判定は、xkcd、Pepper&Carrot、8comic の一部の閲覧ページ、漫画櫃のデスクトップ版とモバイル版の閲覧ページ、nhentai.net のギャラリーと閲覧ページに対応しています。キャッシュする画像1枚あたりの上限は 32 MiB です。

## ビルド

`node scripts/build.mjs` を実行すると `dist/komaglide.user.js` が生成されます。第1引数に出力先ディレクトリを指定できます。インストール後は端末で閲覧、画像の保存、本棚の利用ができます。

新バージョンを公開するには、`src/userscript.meta` の `@version` を上げ、再ビルドしてソースコードとインストール用スクリプトを `main` にプッシュします。スクリプト管理ツールは次回の更新確認で新バージョンを検出します。

## 対応サイトを追加する

`src/sites/` に JavaScript ファイルを追加し、`siteAdapters.push(function (root, address) { … })` でサイト用アダプターを登録します。[Pepper&Carrot のアダプター](src/sites/pepper-carrot.js)を参考にしてください。ビルドではファイル名順にアダプターを取り込み、最後に[汎用のサイト判定](src/sites/generic.js)を試します。

- `root` は現在のドキュメント、またはまだページに挿入していない次のページの内容です。`address` はそのページの URL です。渡された `root` から読み取ると、どちらの閲覧方法でも同じアダプターを使えます。
- 対象外のページでは `null` を返します。対象ページでは安定した `chapterId`、`chapterTitle`、`chapterUrl`、`workId`、`workTitle`、`entries` を返します。各エントリーには本編画像の要素 `img` と 1 から始まるページ番号 `index` を含めます。作品が特定できない場合は作品の項目を空にします。
- 総ページ数が分かる場合は `total` を、リーダーで最初に表示するページは `startIndex` を指定できます。`nextPage` は同じ話の次のページ、`nextChapter` は次の話を指します。省略すると汎用のリンク判定を使い、`null` を指定するとそこで終了します。継続読み込みは同一オリジンに限られます。
- スクロールに合わせて画像を読み込むサイトでは、`revealPage(index)` で配信元ページの該当箇所までスクロールし、見つかったかどうかを返せます。ポップアップリーダーは本棚を先に確認し、ページが未保存で配信元サイトから画像 URL が提示されていない場合にのみこの関数を呼び出します。
- 画像を1枚ずつ表示するサイトでは、非同期の `resolvePage(index, signal)` を実装できます。リーダーは本棚を先に確認し、ページが未保存なら配信元サイトのページ選択を操作します。ページ番号と読み込んだ画像が一致してから、そのページのエントリーを返します。[漫画櫃のアダプター](src/sites/manhuagui.js)が実装例です。
- 各ページを個別に取得できるアダプターでは、`parallelPages: true` を設定し、`defaultParallelPreload` で同時先読み数（1〜6、省略時は3）を指定できます。閲覧設定でサイトごとに変更でき、「サイトの既定値」を選ぶと元に戻せます。
- 再ビルドして生成されたスクリプトをインストールします。話を直接開く、配信元のタブで続けて読む、ポップアップリーダーを使う、メニューから本棚を開くという4つの場面で、ページ順と通信を確認してください。

## テスト

[単体スクリプトのテスト](tests/standalone.cjs)では、模擬の漫画ページを使い、モバイルサイズでの自動保存、タブを閉じた後に同じ画像を読み込めること、別サイトのスクリプトメニューから本棚を開けることを確認します。WebKit 版は `TEST_BROWSER=webkit node tests/standalone.cjs` で実行できます。

[デスクトップ統合テスト](tests/browser-smoke.cjs)では Chromium と公式の Tampermonkey を使用します。[8comic](tests/8comic.cjs)、[漫画櫃](tests/manhuagui.cjs)、[サイトごとの容量上限](tests/library-capacity.cjs)のテストもあります。ブラウザーのテストには Playwright Core と対応するブラウザーが必要です。
